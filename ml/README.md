# Valqora ML Module

This directory contains the machine learning pipelines for Valqora, including data preprocessing, revenue leakage detection, churn/recovery prediction, and model inference.

## 📁 Directory Layout

```text
ml/
├── requirements.txt      # Python dependencies
├── README.md             # ML module documentation
└── src/
    ├── __init__.py
    ├── dataset.py        # Dataset loading & synthetic feature engineering (placeholder)
    ├── train.py          # Model training pipeline (placeholder)
    └── inference.py      # Prediction & decision inference engine (placeholder)
```

## 🚀 Setup

```bash
# Create virtual environment
python -m venv .venv

# Activate virtual environment
# Windows:
.venv\Scripts\activate
# Unix/MacOS:
# source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```
