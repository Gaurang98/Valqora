# Valqora Data Storage

This directory holds synthetic datasets used for training, evaluating, and demonstrating Valqora ML models and analytics engines.

## 📁 Directory Structure

- `raw/`: Raw synthetic event logs, subscription histories, invoice records, and customer profiles.
- `processed/`: Cleaned, normalized, and feature-engineered datasets ready for ML model training.

> **Note**: Do not commit confidential or production credentials/data.
